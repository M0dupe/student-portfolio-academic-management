# Student Portfolio & Academic Planner

A responsive multi-page student portfolio created for the COS 106 Introduction to Web Technologies practical project.

- **Institution:** MIVA Open University

## Pages and features

- **Home:** Welcome section and introduction.
- **About:** Education, career interests, skills and hobbies.
- **Projects:** Three sample student projects and an HTML video element.
- **Planner:** Add tasks, mark them complete, delete tasks and clear completed tasks. Tasks are saved in the browser using local storage.
- **Contact:** Client-side validation for required fields, email format and digits-only phone number. The form is a demonstration and does not send messages.

## Technologies

HTML5, CSS3 (Flexbox, Grid and responsive media queries), and vanilla JavaScript.

## Run the website locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build tools or package installation are required.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After GitHub Pages finishes publishing, copy the website URL shown in the Pages settings.
